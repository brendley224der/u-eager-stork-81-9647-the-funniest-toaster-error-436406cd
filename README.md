Entrants write one line, at most 120 characters: the error message a kitchen toaster shows its owner when something goes wrong. It can be deadpan, apologetic, quietly dramatic or plain absurd, as long as it reads like a real message on a real appliance and makes someone laugh. A judge model compares two entries at a time on funniness, freshness and tightness, in private rounds, and the best line takes the reward.
